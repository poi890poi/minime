# Evaluation attribution and limits

The input file is a deterministic subset of previously published MinIME
evaluation inputs, with source file and line identity on every row. Selection
removes reference outputs and retains simulated romanization, partial readings
and errors. No new dictionary entries are derived from this work.

Conversation adaptations retain the attribution and CC BY-SA 4.0 terms in
[the conversation notice](../language-contract-benchmark/conversations/NOTICE.md):
RealPersonaChat (Yamashita et al., Nagoya University); ASDC (Yuta Hayashibe,
Megagon Labs); 媠聲一千 (薛仲志, 賴麗格, 蔡俊傑); and the ChhoeTaigi
digitization of 高積煥 and 陳邦鎮's Taiwanese beginner vocabulary.

Other regression rows retain the existing source lineage in
[the contract manifest](../language-contract-benchmark/manifest.json) and
[coverage manifest](../input-modes/coverage-manifest.json). They include
dictionary-derived readings and essay inputs, and cannot establish independent
coverage. The phone subset retains the [provider notice](../japanese-provider-integration/NOTICE.md).
See the pinned source catalogs and upstream notices for original ownership.

Derived input exports here are CC BY-SA 4.0. Ordered output digests contain no
recoverable candidate text. Benchmarks are regression/performance evidence,
not accuracy estimates, human touch measurements or fresh holdout results.
