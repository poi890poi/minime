# MinIME 0.8.4 (32)

Build/release and product identity change. Display names: MinIME — Pinyin for
Taiwan / MinIME — 台灣多語拼音鍵盤. Application ID: app.minime.keyboard.
Java namespace and component class names remain dev.minime.ime; Android's
application ID is independent of these implementation names.

Impact: this installs separately from dev.minime.ime. Export settings and learned
words in the old app and import the backup into the new app; enable and select
the new keyboard. No automatic migration or uninstall. Previously created
registration APKs for dev.minime.ime do not register this new package name.

Scope: localized launcher, IME and settings title; new package/version; update
current test tooling's installation targets and release inventory validation.
No dictionary or suggestion/ranking changes, no experimental Japanese provider
activation, no account token in the released assets. Existing local core and
pinned desktop checks precede the Android build. Validate resolved component
classes, locale labels, package ID, all ABIs, signatures and packaged assets.

The AAB uses the existing dedicated upload key. The sideload release APK is
signed with that same key for local review, not the old Android debug key.
If Play App Signing later uses a different app signing key, this sideload APK
will not update to that Play build directly; use the Play-generated APK when
available for a matching installation identity. No Play configuration or upload
is performed. Rights review and Android 16/16 KB runtime checks remain open.
