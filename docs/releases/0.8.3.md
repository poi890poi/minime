# MinIME 0.8.3 (31)

Release package preparation, September 12, 2026. Production code baseline:
21fefdc. This is a build/release change: increment the version and package the
validated runtime, sources and existing publishing materials. No dictionary,
ranking, stored preferences, application ID or signing identity changes.

Changes since the previous package include faster Java dictionary lookup,
reused typing-validation patterns, and skipping unused Pinyin analysis in modes
that exclude Chinese. The experimental native Japanese converter remains test-only.

Existing evidence for this runtime: 306,303 core assertions, 13,014 pinned desktop
Rime inputs, unchanged ordered lookup/acceptance comparisons and two final phone
pipeline runs. Aggregate warm pipeline p95 improved from 50.55 ms to 42.82–43.70 ms;
this is not physical touch-to-display latency. The small casual-chat subset still
has a 51.73–54.65 ms p95. See ../japanese-pipeline-performance/README.md and
../java-lookup-performance/README.md for corpus, measurement and coverage limits.

Packaging verification must cover version, release manifest, signatures, four
ABIs, asset identity, native alignment, lint, source archives and checksums.
Keep the installable debug test build distinct from unsigned production files.
Never package device backups, signing keys, evaluation APKs or research corpora.

Upload signing credentials are absent. The UD underlying-text rights review in
sources/release-policy.json and Android 16 / 16 KB runtime certification remain
open. This package is prepared for review, not cleared for Play upload. Building
does not resolve these gates. No device operation or public publication is part
of this packaging run.
