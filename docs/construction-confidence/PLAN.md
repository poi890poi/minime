# Chinese live-construction benchmark contract

Requested September 12, 2026 before production changes. Benchmark Rime and Java
construction as mechanisms, not only specialist dictionaries or one complaint.

Native transport must retain true candidate type, component count, native quality
and path weight. The MSVC metadata evaluator uses pinned Rime 1.16.1 and compares
every C++ page's text/count with the same session's public C API. No inferred
dictionary-membership flag substitutes for native sentence identity. The initial
origin audit measured attestation only and is not a hit-rate benchmark.

Freeze Taiwan.md prose documents/clauses before querying. Existing audited documents
are development/regression; new disjoint pinned documents are reserved for validation.
No source output, word choice or ranking result determines document selection.
Readings come from original McBopomofo annotations with explicit ambiguity rejection,
not the Rime candidate under test. This shares lexical lineage and limits coverage
claims; reference Han text always comes from source prose. Retain source hashes and
all exclusions. Do not convert Simplified corpora.

Report full, partial, initials and mixed phonetic conditions separately. Primary
construction hit is exact source-text reconstruction, conditional on construction
being emitted. Also report generation frequency, prefix-supported output, first
row/page reference coverage, default-reference mismatch, and native query latency.
A mismatch is not automatically semantic nonsense: homophones and valid alternate
sentences exist. Random spelling controls have no intended phrase and measure forced
construction incidence only. Keep complete and partial inputs distinct.

Candidate native quality is not assumed to be a calibrated probability. Compare
constant quality, length/component-normalized path weights and baseline behavior
on development first; keep negative results. Choose a general confidence policy
only if it discriminates correct constructions on independent validation. Otherwise
preserve unknown confidence honestly and demote unsupported construction relative
to attested choices, without deleting valid multiword construction wholesale.

Runtime may see typed input, enabled dictionaries, native metadata and explicit
local choices. Corpus labels/document identities may never enter runtime ranking.
No entry blacklist, per-name exception, rare-glyph ban or source frequency invention.
Preserve exact phrases, partial-consumption semantics, English literal recovery,
secure-field policy and intentional learned choices. Audit automatic phrase-learning
feedback separately; do not claim source-dictionary modification from emitted text.

Conversation gap: the existing file named conversation-ranking contains Chinese
UD word/glyph audits, not a natural Taiwan Mandarin conversation benchmark. Sinica
MCDC8 requires licensed access; NCCU's public site currently fails to load. Continue
source discovery, report missing conversational evidence explicitly, and never label
essay or translated gloss scores as spontaneous-conversation accuracy.

Before shipping: shared-core regressions, pinned desktop comparison, fresh validation,
confidence calibration/error analysis, latency and all-ABI Android transport build.
Phone integration requires a fresh explicit handoff and lease. No phone is reserved
now. Release preparation is preserved in independent commits; publication is blocked
on this quality issue and the already documented rights/runtime/account gates.

## Policy frozen before reserved decoding

Development comparison rejects placing every attested prefix before constructions:
full-spelling first-eight reconstruction falls from 596/1275 to 168/1275. Retain
three early nonconstructed choices, then unverified constructions, then remaining
choices. This preserves native-only development first-eight hits in all conditions.
Native Sentence quality is constant zero; normalized path weight does not support
a reliable high-confidence threshold. Therefore confidence remains unknown, not a
fabricated probability. Explicit local choice votes may override the demotion.

An unverified construction cannot be the automatic whole-token choice: prefer an
attested whole-input choice, otherwise preserve literal input. This intentionally
trades automatic reconstruction for explicit selection. Never promote a prefix to
whole-token Space acceptance. Optional phrase learning must not turn automatic
constructed acceptance into an attested entry. Explicit selection can still learn.
The same policy applies to Java and native Chinese construction, after merging.

Validate first-eight coverage and automatic choice on all 6120 reserved conditions,
then report actual shared-core results separately from native-only counterfactuals.
No thresholds will be tuned on the reserved output. Conversation coverage remains
unverified. Ranking adds one linear pass over the bounded candidate list and no
model/data assets; benchmark its core overhead separately from native query time.
