examples up to six syllables. No place, name, Mandarin-frequency or phrase-ID gate.
Original source POJ is preserved; example lookup removes tones and encodes o͘ as oo
and ⁿ as nn. Terminal sentence punctuation is omitted from phrase output.
This historical beginner source contains dated vocabulary, not measured modern
usage frequencies. Unsupported example syntax is excluded by general format rules.
