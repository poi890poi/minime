# Evaluation data attribution

These exports are evaluation material, not MinIME dictionaries. They contain
excerpts and adaptations of the sources below. Source IDs and document/turn
identities accompany each reference. Source spelling is retained for Japanese;
machine-generated reading annotations are marked as silver. Taiwanese Tâi-lô
readings are converted to POJ, with original aligned text retained in the turns
export. Input prefixes and errors are mechanically generated.

- **RealPersonaChat**, Sanae Yamashita, Koji Inoue, Ao Guo, Shota Mochizuki,
  Tatsuya Kawahara and Ryuichiro Higashinaka, Nagoya University dialogue group:
  [repository](https://github.com/nu-dialogue/real-persona-chat), CC BY-SA 4.0.
  See the included `real-persona-chat-LICENSE` and upstream README.
- **Accommodation Search Dialog Corpus**, Yuta Hayashibe / Megagon Labs:
  [repository](https://github.com/megagonlabs/asdc), CC BY 4.0 for corpus texts
  and annotations. Code has separate Apache 2.0 terms; see `asdc-LICENSE.txt`.
- **媠聲一千**, Sih Tiong-tsì (薛仲志), Luā Lē-keh (賴麗格) and
  Tshuà Tsùn-kia̍t (蔡俊傑), with the iTaigi/MOE loanword-list lineage credited
  by the authors: [repository](https://github.com/SuiSiann/SuiSiann-TsitTshing),
  CC BY-SA 4.0. See `suisiann-thousand-README.md`.
- **A Basic Vocabulary for a Beginner in Taiwanese** (1956), Ko Chek-hoàn
  (高積煥) and Tân Pang-tìn (陳邦鎮), digitized by the ChhoeTaigi community:
  [pinned source](https://github.com/ChhoeTaigi/ChhoeTaigiDatabase/tree/b33c6a1fcc2d11a2962e76b6055d528d11677c3b).
  See the included `taiwanese-basic-README.md` for contributors,
  CC BY-SA 4.0.
