# Independent Taiwan reading reference audit

September 24, 2026. Existing source ID `moe-dictionaries`, reference/evaluation
only. No production extraction or distribution of edited dictionary text.

Acquire the original MOE concise and elementary dictionary text archives from
the publisher's public-release pages, preserve original bytes locally, and pin
versions, URLs, hashes, licences and schema. The public terms are CC BY-ND 3.0
Taiwan. Keep source archives, parsed entries and per-glyph joins in ignored
artifacts; publish only our audit code and aggregate findings. This does not
resolve or extend derivative production-use rights.

Before examining the archives, freeze comparison scope: every single-Han source
entry in the official releases; all primary/secondary/tertiary McBopomofo rows;
and all 2,000 full-spelling word cases in the existing encyclopedic evaluation.
For source-priority comparison use exact Bopomofo readings, moving the neutral
tone mark to the trailing position and representing an omitted first tone
consistently. Do not merge other tone distinctions or change pronunciation letters.
Record unparsed records and missing coverage explicitly. For the evaluation
audit use source-provided Pinyin when available; ambiguous readings remain
ambiguous rather than being forced to the proposed ranking model's preferred one.

Report covered/uncovered glyphs, primary readings present/absent from each
reference, and multiple reference readings without interpreting source order as
frequency. The concise dictionary is intended for learners and selects vocabulary
using frequency studies; the elementary dictionary explicitly omits rare readings.
Neither is a frequency model for adult conversations, names or specialist terms.
Their presence/absence is an independent review signal, not an automatic promotion
or deletion rule. Never tune against the individually inspected examples.

The existing corpus and Google observations have already been inspected. A new
reference join adds evidence about their pronunciation assumptions; it does not
make those queries a fresh holdout. Preserve earlier reports and do not silently
rewrite labels or claim source-derived scoring as independent model accuracy.
