# Flagged Taiwanese Han example

The first richer capture exposed `chia̍h` with the Han example `炸` in the
expanded `chiah` list. Preserve `07-taiwanese-choices-original.png` and its
`initial-store-candidates.json`; it is not an approved store image.

The shipped `app/src/main/assets/paired-forms.tsv` attributes this exact pair to
`itaigi:1732`. Other source-backed entries in the same file use the eating sense,
including `chia̍h-pá` / 食飽 (`taihoa:12942`) and 食飽未. This flags the suitability
of the single Han example chosen for a common reading; it does not establish that
every upstream sense is invalid. A systematic source/paired-form selection audit
is needed, with no per-word exception or demo-specific promotion.

No production fix was made as part of this screenshot task. The final store scene
07 demonstrates actual tap/hold output using lí hó / 你好 and records both actions.
That scene change does not close this quality finding or certify the dictionary.
